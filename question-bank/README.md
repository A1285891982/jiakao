## 文件说明

| 文件 | 内容 |
|---|---|
| `ke1.json` | 科目一 2540 题 |

## 字段结构

每个 JSON 文件结构为 `{"meta": {...}, "questions": [...]}`，`questions` 中每条：

```json
{
  "num": 1,                 // 本科目内序号
  "id": "20190410...",      // 原库唯一 id
  "type": "判断|单选|多选",
  "question": "题干",
  "options": [{"key":"A","text":"选项文本"}, ...],
  "answer": "B",            // 多选为 "ABC"（长度>1 即多选）
  "explanation": "解析（已剥离 HTML）",
  "skill": "答题技巧 / 口诀",
  "chapter": "1",           // 章节 id
  "difficulty": 1,          // 难度
  "errorRate": "4.3",       // 易错率 %
  "hasImage": true,         // 是否含图
  "imageUrl": "http://..."  // 题图远程地址（chetailian CDN，可能需联网加载）
}
```
